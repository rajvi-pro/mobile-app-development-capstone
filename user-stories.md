# Nine User Stories

1. As a new user, I want to create an account so that I can access the app.
2. As a returning user, I want to log in so that I can reach my home screen.
3. As a user, I want to see a list of items so that I can explore available content.
4. As a user, I want to open an item detail page so that I can read more information.
5. As a user, I want to save favorite items so that I can find them again.
6. As a user, I want my basic app preferences and saved favorites to persist after restarting the app.
7. As a user, I want to fetch sample content from an external API so that the app can show current remote data.
8. As a user, I want a settings menu and settings screen so that I can review and change app preferences.
9. As a user, I want to configure and test a notification so that I can verify notification-related functionality.

Note: These are starter user stories. Adjust them if your course's required user stories differ.
