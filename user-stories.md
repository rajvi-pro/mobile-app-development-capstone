# User Stories — Everyday App

1. As a user, I want to create an account so I can access the app.
2. As a returning user, I want to log in so I can continue using the app.
3. As a user, I want to see a home screen so I can discover useful content.
4. As a user, I want to open a detail page so I can read more about an item.
5. As a user, I want to save and view favourites so I can revisit useful items.
6. As a user, I want my profile details saved locally so they remain on my device.
7. As a user, I want the app to load sample content from an external API.
8. As a user, I want to access settings so I can manage app features.
9. As a user, I want to receive a test notification so I can verify notifications work.
